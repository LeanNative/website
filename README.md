# LeanNative website

The static site for https://leannative.com, served by GitHub Pages from `docs/` on `main`.

- `docs/index.html`, `docs/style.css`: the page (plain HTML and CSS, no build step, no scripts)
- `docs/CNAME`: the custom domain
- What is left lives in [LeanNative's issues](https://github.com/LeanNative/leannative/issues), not on the page.

Preview: `python3 -m http.server -d docs`
